## Intent
Пользователь утвердил автономную разработку только из согласованного плана WB: Director выбирает и декомпозирует работу, OpenHands реализует, Harper проверяет, независимое ревью допускает конкретный commit до PR. После результата не требуется новое «гоу». Приёмка: три полезные независимые задачи подряд через реальный маршрут до PR.
## Boundaries & Constraints
Always: только серверные source/state; Paperclip единственный планировщик Director; одна разработка одновременно; подтверждённые base/head и фиксированные разрешённые файлы; числа считает код; история неизменяема, отменённая попытка не публикуется.
Ask First: merge, production release, расширение продуктового плана или разрешений.
Never: WB WRITE, Simone, копии проекта на Mac, произвольный shell от модели, сброс unknown, bypass проверки/публикации.
## I/O & Edge-Case Matrix
| Ситуация | Поведение |
|---|---|
| PR готов | Следующая независимая ready-задача запускается автоматически |
| Зависимость только ready_pr | Ждать проверенного merge, не считать зависимость реализованной |
| Локальный сбой | До двух новых попыток после подтверждённой остановки; затем blocked; независимая работа продолжается |
| Потеря ответа/unknown | Сверить тот же idempotency key и внешний запуск; не дублировать работу |
| Отмена | Сначала существующий cancel/fence; никаких PR старой попытки |
| Диск/доступ/общий исполнитель | Остановить admission, показать конкретную причину |
| Очередь меньше трёх | Director предлагает задачи по закреплённым требованиям; отдельная проверка и регистрация обязательны |

## Tasks & Acceptance
- [ ] Постоянная очередь в SQLite Bridge: id, requirement_id, цель, acceptance, base_sha, allowed_paths, depends_on, proposal/policy/review fingerprints, state, attempts, timestamps, external ids, evidence/PR.
- [ ] Policy закрепляется оператором из принятого плана WB. Модель не выбирает profile, команды, секреты, каталог установки или права. Независимое ревью exact proposal + детерминированная проверка до ready.
- [ ] Регистратор добавляет одинаковый immutable template в Bridge/Harper/worker и проверяет три receipt; частичное обновление не ready. Владельцы конфигов сохраняются; для нового template reload только idle без uncertain publication.
- [ ] Диспетчер использует одиночные manifests existing night_batch; пять минут и completion-trigger; одиночная lease, устойчивый idempotency, recovery без двойного запуска. Действующий конечный режим сохраняется.
- [ ] Небольшие задачи пополняются из WB, а не из произвольного текста research. Planning и execution раздельно видны; планирование Director запускается Paperclip.
- [ ] GLM вне 09-13 МСК будни, прежние adaptive alternatives и 48 research intents/day; OpenHands Sol medium; без ultra. Явный retry unknown read-only, old event неизменен.
- [ ] Статус и отчёт в 08:00 МСК: текущая/следующая работа, last progress, blocker, PR; без повторного спама.
- [ ] Начальные задачи: reproducible daily WB automation+tests; warehouseName-only drift с сохранением старых payload/hashes; точный статус real WB collection для Director. Независимые allowlists, отдельные PR.
