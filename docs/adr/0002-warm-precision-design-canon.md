# 0002. Warm Precision как дизайн-канон веб-кабинета

## Контекст

Кабинет выглядел дефолтным холодным SaaS-шаблоном (shadcn slate) с пустыми заглушками-карточками. Отзыв Mike: «очень слабо выглядит». DESIGN.md описывал канон Warm Precision со статусом «предложение, ожидает утверждения».

## Решение

Warm Precision утверждён как канон (Mike, 2026-08-25, интервью по фронтенду): ivory-канва #f7f4ef, белые поверхности, hairline #e7e5e4, violet #6d28d9 только на действиях, Inter + IBM Plex Mono, hairline-разделители вместо теней, радиусы 4/8. Тёмная тема с первого дня, тёплая stone, light основная.

## Почему

Слейт-дефолт отброшен: именно он вызвал «очень слабо выглядит», холодный серый не отличает кабинет от дашбордов конкурентов, узнавания ноль. По интервью №8 зафиксирован анти-эталон с двух сторон: SaaS-шаблон (сетка одинаковых карточек, градиенты, графики ради красоты) и «госуслуги» (канцелярит в текстах, перегруженные таблицы). Тёмная тема как единственная отвергнута (интервью №4): light основная, тёплая dark рядом. Референсы (Linear, Stripe, Superhuman, Triple Whale) заимствуются точечно по паттернам, а не стилизацией под один из них целиком.

## Последствия

Каждый новый экран обязан держаться канона; отклонения ловит /styleguide и ревью, свободы «нарисовать по-своему» больше нет. Violet только на действиях: красить им данные нельзя, это дисциплина. Чипы статусов живут двумя наборами (700-step в light, 300-step с тёмным текстом в dark) ради AA-контраста в обеих темах. Смена канона теперь равна переделке токенов globals.css и всех экранов, то есть решение дорого в отмене. Однострочный статус «Утверждён Mike 2026-08-25» в DESIGN.md закрыл вопрос «чей вкус главный».
