## TL;DR

PROXIMA AI - AI Daily Manager для WB-кабинетов: **web-кабинет AM** с ежедневными сигналами (причина + альтернативы + ₽-оценка + SourceRef), Decision Inbox с фиксацией решений и автосверкой expected vs actual. Путь: внутренний инструмент Proxima (M2) -> первый платящий клиент за AI-аналитику в 6 мес -> SaaS на 50+ кабинетов (M3). Первая реальная ценность - 1-2 месяца, value-треком параллельно с M1.

## 1. Продукт одним абзацем

Account Manager Proxima обслуживает портфель WB-кабинетов. Сегодня мониторинг портфеля ручной: выгрузки, пересчёты, портфель просматривается неравномерно, сигналы теряются. AI Daily Manager закрывает это: каждый кабинет каждое утро проверяется автоматом; всё аномальное - с причиной, доказательствами и рекомендацией - попадает в Daily Brief; человек подтверждает, действует и фиксирует результат; система учитывается на исходах (Decision Memory). Первый этап - read-only: система рекомендует, человек выполняет.

## 3. Урок прошлого цикла (встроен в процесс)

Прошлый продукт удалён из-за **качества данных**: выводам и цифрам нельзя было верить. Защита:

1. **Verified-only для цифр.** Любое число в клиентском выводе прослеживается до официального WB-артефакта (M1-контракт: SHA-256 provenance, reconciliation, fail-closed releases). Это уже строится - не режется.
2. **LLM не считает.** Метрики - детерминированный код; LLM объясняет и связывает причины, каждый факт со SourceRef; независимый reviewer блокирует unsupported claims (07-quality doc).
3. **Value-трек с маркировкой доверия.** До завершения M1 сигналы идут из staging-данных с явной пометкой `unreleased` (паттерн Phase 2.1) - ценность без обмана.
4. **Валидация до кода.** Каждый продуктовый эпик открывается проверяемой гипотезой и закрывается решением Mike, а не «написано и работает».

## 4. Стадии продукта

### M1 - Data Foundation (в работе)

Текущий ROADMAP, фазы 2-8. Не перепланируется. Выход: verified данные пилотного кабинета + Data Health + daily ops. Экономит M2 от смерти на данных.

### M2 - AI Daily Manager (внутренний) - целевой вход в ценность через 1-2 мес

**Гипотеза M2:** AI-детекция сигналов + объяснимые рекомендации ловят отклонения, которые AM пропускает, без критических ошибок.

**Экономика боли (интервью 2026-08-16):** AM ведёт 1-3 кабинета и тратит >60 мин/день на мониторинг одного; главная боль - не сбор, а **интерпретация** («что случилось и почему»). Ядро продукта - готовый диагноз, LLM-слой не опция.

**Продукт v0 (решения интервью №1-38 + рекомендации №39-50):**

| Слой | Решение |
|---|---|
| Web UI (v0, не Telegram) | GYR + счётчики сверху; дайджест + critical отдельно; **Decision Inbox** (принял/отклонил/причина) - зародыш Decision Memory; чат Q&A - после стабилизации web |
| Telegram | Только critical-алерты и инциденты (паттерн 02-01A) |
| Сигналы | До 10/день на кабинет; baseline скользящая 7/14/28 с сезонностью дня недели (Anodot-паттерн, уточняет №30); пороги глобальные + per-client из Client Passport; ₽-оценка «стоимость молчания» на каждом (№14) |
| LLM | Диагноз: primary + 2-3 альтернативы + unknowns (№15); тон объясняющий (№18); SourceRef всегда (№19); независимая модель для reviewer, BLOCK с дня 1 (№39-40) |
| Verification | Автосверка expected vs actual через N дней после действия (№28) - главный дифференциатор |
| Клиент | Недельный PDF-отчёт от AM (№17); клиент не видит внутренний бриф |
| Mike | Недельная сводка портфеля + инциденты сразу (№10) |
| Ритм | Данные daily к 07:00 MSK; бриф фикс 07-08 MSK; выходные per-client (№6-7, №29) |

**Сценарии - 11 штук, волнами (подтверждено):**

| Волна | Сценарии | Источники данных |
|---|---|---|
| **W1 (нед. 1-3)** | SCN-008 data quality, SCN-001 продажи, SCN-005 OOS | Statistics API (+ Advertising API подключаем как источник) |
| **W2 (нед. 4-6)** | SCN-007 DRR, SCN-002 заказы, SCN-004 маржа | Advertising, Statistics |
| **W3 (нед. 7-10)** | SCN-009 отзывы, SCN-010 акции, **SCN-011 контент-алерты** (Helium-паттерн) | Feedbacks API, Content API + позиции |
| **W4 (M3-вход)** | SCN-003 полный P&L, SCN-006 избыток + 12-мес прогноз (SoStocked combo-forecasting) | COGS с онбординга (№36), склад клиента руками AM (№38) |

**Методология SCN-001/002:** декомпозиция U x CVR x AOV (Rakuten R-Karte) + бенчмарк MPStats «категория vs ты» (Lebesgue-паттерн) - в MetricAuthority v1.

**Данные (№31-38):** WB API Statistics/Analytics/Finance/Advertising (сразу)/Feedbacks/Content; MPStats-бенчмарки (аккаунт есть, №35); цена/СПП daily (№34); COGS собирает AM при онбординге; XLSX - только пилот.

**Гейты M2:**
- **V1 (value gate, метрика №47):** 1 сквозной сигнал: AI нашёл -> AM подтвердил -> клиент получил результат. Цель 1-2 мес.
- **V2 (portfolio gate):** 3-5 кабинетов на daily-мониторинге; AM-время измерено до/после.
- **V3 (payment gate):** клиент платит за AI-аналитику. Цель 6 мес. Pricing: фикс за кабинет/мес, вилка 10-20k ₽ (№44-45); пилот Богатовой бесплатно до V3 (№46).

**Автоматизация:** R1 после V2 = пауза РК при OOS (Pacvue-паттерн, №41); approvals в web Decision Inbox (№42); kill switch - только Mike (№43).

**DoD M2 (№50):** 5 кабинетов на ежедневном мониторинге, AM не мониторит вручную.

### M3 - Продуктизация (открывается после V3)

Multi-tenant SaaS на 50+ кабинетов: onboarding через Client Passport, клиентский dashboard, биллинг, изоляция. Тариф = кабинет + полоса SKU (Sirena-паттерн №10), наценка за verified-слой и AM-обёртку. WB WRITE - отдельные гейты после стабильного M2.

## 8. Метрики продукта (M2)

| Метрика | Тип | Цель-ориентир |
|---|---|---|
| Time-to-detect отклонения | Продуктовая | Дни -> часы (daily cycle) |
| AM-время на мониторинг кабинета | Продуктовая | Baseline >60 мин/день (подтверждён интервью) -> цель -50%+ к V2 |
| Signal recall / false positive | Качество | Порог после baseline; critical errors = 0 всегда |
| Recommendation acceptance rate | Качество | Порог после baseline |
| Подтверждённые исходы (expected vs actual) | Бизнес | 100% закрытых сигналов имеют verified outcome к концу M2 |
| Кабинетов на ежедневном мониторинге | Масштаб | 1 -> 5 (DoD M2) |
| Платящий клиент | Бизнес | >= 1 к 6 мес (V3) |

## 9. Мировые паттерны (полное досье: `.planning/research/GLOBAL-LANDSCAPE-2026-08-16.md`)

Категория подтверждена на 12 рынках: Amazon Amelia, Shopify Sidekick Pulse, Taobao 生意管家 (1M+ продавцов/нед), CoupangData (утренний отчёт в KakaoTalk), Trendyol Ortak, Flipkart Setu, Rakuten RMS AI.
