# Plan 02-01 - Immutable official WB XLSX intake foundation

## Objective

Build one deterministic command that accepts an official manual WB XLSX plus explicit metadata, stores exact bytes outside Git under their SHA-256 address, and publishes a contract-valid immutable manifest only after the raw file is durable. The implementation is proven against synthetic structural fixtures and explicit crash injection; it does not parse workbook data yet.

## Must haves

- Raw bytes are persisted, hashed and fsynced before any XLSX parsing, staging, facts or UI path.
- Store root is private and outside Git; symlink, unsafe-permission and repository-root attacks fail closed.
- Artifact identity is SHA-256 based, retry-safe and cannot silently overwrite conflicting metadata.
- Crash injection covers before raw publish, after raw publish and before manifest publish; retries leave no duplicate public state.
- No live WB/Torgstat/API/session behavior, no browser dependency and no release pointer enter this plan.
