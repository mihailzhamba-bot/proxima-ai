# DoD-чеклист задач среза (PMM)

- Задача: PMM-12 (WBS AIOS-DEL-005), sprint-0
- Создан: 2026-08-27
- Формат записи: 7 пунктов «проверь X» + канон каждого пункта; аудит — копи-паст шаблона из секции «Аудит» в Jira-комментарий закрываемой задачи
- Каденция: прогон при закрытии каждой задачи Jira-проекта PMM; вердикт таблицей в комментарии задачи
- Scope: все задачи Jira-проекта PMM (срез M2/M3, sprint-0/1 и далее). Задачи PA (M1) живут по `AGENTS.md` §Definition of Done + фазовым гейтам — чеклист на них не распространяется

## Приоритет

Каноничны `AGENTS.md`, `RULES.md`, DEC-006. Чеклист - операционный вид для закрытия задачи: краткая формулировка + указатель. При расхождении канон выигрывает; расхождение - баг чеклиста, правится здесь же со ссылкой на канон.

## Применение

- Описание новой задачи среза ссылается на этот чеклист; если задача создана без ссылки - refinement добавляет (AC#2 PMM-12). Достаточно строки: «DoD: docs/governance/dod-checklist.md».
- При закрытии задачи исполнитель прогоняет все 7 пунктов и оставляет в задаче аудит-комментарий по шаблону ниже (AC#1 PMM-12).
- Пункт 7 чеклист применяет и к себе: перед переводом задачи в Done проверь её собственные блоки/ссылки.

## Аудит

Вердикты: `pass` - выполнено; `justified` - не выполнено с явным обоснованием; `n-a` - пункт неприменим к задаче, причина в комментарии. `fail` задачу не закрывает - сначала фикс или обоснование.

Шаблон (копировать в комментарий закрываемой задачи):

## Правила ведения

1. Пункты чеклиста не редактируются вне задачи, ссылающейся на канон: новое требование среза сначала попадает в `AGENTS.md`/`RULES.md`/DEC, потом в чеклист строкой с указателем.
2. Вердикт без доказательства (файл/PR/коммит/решение Mike) недействителен; нет данных - `UNKNOWN` с пометкой, что добыть.
3. Первый прогон - ретро-аудит закрытых задач sprint-0 (PMM-30, PMM-9, PMM-10) и закрытие самой PMM-12; их комментарии - эталон формата.
