## Правила ведения

1. Допущение = проверяемое утверждение с запланированным пересмотром. Вероятностный ущерб без проверки - в risk-register, не сюда.
2. Новая запись получает следующий ID (A-12, A-13...); ID не переиспользуются.
3. Статус `confirmed`/`refuted` требует ссылки на доказательство (файл:строка, коммит, ссылку Jira, дату интервью).
4. Ретро спринта: реестр просматривается целиком; каждая запись получает обновление статуса или явное «без изменений» (AC PMM-9).
