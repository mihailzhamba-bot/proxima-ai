## Правила ведения

1. Риск = вероятностный ущерб; проверяемое допущение живёт в assumptions-register, не тут.
2. Score X = обязательный ранний признак + владелец; без признака запись не принимается (AC PMM-10 по №11-13 распространено на всех).
3. Новые ID инкрементируются (R-14...), не переиспользуются; закрытие риска - только со ссылкой на исчезновение условия.
4. Ретро спринта: пересмотр вероятности/ущерба по фактом спринта, обновление дат пересмотра.
5. Кандидаты на добавление: недоступность LLM-провайдера (после PMM-31 - см. зависимости задачи).
