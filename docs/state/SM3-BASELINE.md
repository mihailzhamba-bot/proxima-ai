# Замер SM-3 «до»: время Mike на утренний просмотр кабинета

Метрика PRD SM-3 (исходный замер `UNKNOWN`). Замер делается ДО релиза 2.6 (после релиза «до» получить нельзя). Пять утр подряд, ведёт Владислав со слов Mike или по самозаписи Mike. Правила: время в минутах, без округления «примерно»; «решение» - что Mike сделал или решил после просмотра (ничего - тоже ответ).

| | | | | | | |
