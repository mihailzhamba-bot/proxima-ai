Дата проверки: 2026-09-02. Уровень: normal - спот-чек только 8 load-bearing claims из дайджестов r1-r3, по одной независимой проверке на claim. Бюджет: 12 веб-вызовов (7 поисковых выдач + 5 прочитанных страниц), исчерпан. Правило: «независимый» = другой издатель с другими исходными данными; страницы того же вендора и перепечатки пресс-релиза независимыми не считаются, но фиксируются как первичное подтверждение.

## 1. MPStats запустил MCP-подключение AI-агентов (Claude, Codex и др.) - unverified

Исходник: MPSTATS, 2026-08-06, https://mpstats.io/media/mpstats/news/produktovye-obnovlenija-za-ijul-2026-goda.

Что нашёл. Первичная продуктовая страница «Подключите аналитику маркетплейсов к AI-агентам» прочитана в этом прогоне: в навигации значится «MCP для AI-агентов» (в блоке бесплатных инструментов), подключение описано как установка скилла командой `npx skills add https://github.com/mpstats-io/claude-code-skills -y -g` плюс персональный API-токен; конкретные агенты (Claude, Codex, ChatGPT, Cursor) на странице по имени не названы - только логотипы (MPSTATS, дата публикации неизвестна, https://mpstats.io/instruments/connect-ai, доступ 2026-09-02). Поисковая выдача показывает публичный репозиторий вендора `mpstats-io/claude-code-skills` - «скиллы для AI-агентов поверх MPSTATS API», «полный справочник MPSTATS API с 122 эндпоинтами и 30+ готовыми скриптами», токен передаётся в заголовке `X-Mpstats-TOKEN` (GitHub / mpstats-io, дата неизвестна, https://github.com/mpstats-io/claude-code-skills, доступ 2026-09-02, по сниппету поисковой выдачи).

Независимый издатель. Два целевых поиска (общий и с ограничением по доменам vc.ru, e-pepper.ru, oborot.ru, retail.ru, shopolog.ru, cnews.ru, tadviser.ru, habr.com, new-retail.ru, uniseller.io) не дали ни одной сторонней публикации именно о MPStats MCP/скилле; обзоры MPStats на vc.ru, blog.click.ru, uniseller.io в сниппетах эту функцию не упоминают (поисковая выдача, доступ 2026-09-02).

Вердикт: unverified. Факт существования подтверждён двумя первичными артефактами вендора (страница + GitHub-репозиторий), но второго издателя нет. Уточнение формулировки: технически это Claude Code-скилл поверх REST API с токеном, а слово «MCP» присутствует как название инструмента в навигации; «Claude, Codex» - интерпретация дайджеста, на странице агенты не названы. Для аргумента о дифференциации claim использовать с пометкой «один издатель».
