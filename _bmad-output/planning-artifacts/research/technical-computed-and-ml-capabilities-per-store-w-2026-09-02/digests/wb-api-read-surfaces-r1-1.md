# wb-api-read-surfaces - round 1

Дата доступа ко всем источникам: 2026-09-02. Ограничение раунда: все 8 прямых запросов к `dev.wildberries.ru` (api-information, news/285, news/297, news/302, docs/openapi/promotion, docs/openapi/analytics, docs/openapi/reports) вернули HTTP 498; `openapi.wildberries.ru/analytics/api/ru/` - «proxy refused the connection». Поэтому факты ниже опираются на (1) поисковые сниппеты, индексирующие официальные страницы dev.wildberries.ru, и (2) одну прочитанную целиком страницу - разбор DEEONE «Wildberries API: домены, методы, лимиты запросов и коды ошибок» (июль 2026). Уровень доверия соответственно снижен: «medium» для сниппетов официальных страниц, «low-medium» для вторичного источника.

## Что искал и что нашёл

### (a) Остатки

В официальной документации существует метод `POST /api/analytics/v1/stocks-report/wb-warehouses` (остатки на складах WB, раздел «Аналитика»), а также отдельный отчёт `GET /api/v1/warehouse_remains` с последующей проверкой статуса и скачиванием (создать → статус → скачать) (Wildberries dev.wildberries.ru, раздел «Analytics and Data», дата публикации unknown, https://dev.wildberries.ru/en/docs/openapi/analytics, доступ 2026-09-02, через поисковый сниппет). По сниппету того же раздела метод «возвращает текущие остатки на складах WB, данные обновляются раз в 30 минут», и это данные «детальной таблицы товаров и виджета детализации по регионам и складам» (Wildberries, unknown, https://dev.wildberries.ru/en/docs/openapi/analytics, доступ 2026-09-02). Разбор DEEONE добавляет практический нюанс: выгрузка остатков «зависит от предварительно загруженных карточек» (DEEONE, 2026-07, https://deeone.dev/blog/wildberries-api-etl-grabli-2026.html, доступ 2026-09-02). Глубина истории остатков, точный лимит и токен-категория метода `stocks-report` в этом раунде не подтверждены - страница не открылась.

### (b) Реклама (READ и мутирующие)

Статистика кампаний отдаётся методом `GET /adv/v3/fullstats` (Wildberries, раздел «Promotion», unknown, https://dev.wildberries.ru/en/openapi/promotion, доступ 2026-09-02, сниппет). По сниппету официальной документации лимит - «максимум 1 запрос в минуту на аккаунт продавца», а «максимальный период, за который можно получить статистику через API, - 31 день» (Wildberries, unknown, https://dev.wildberries.ru/en/openapi/promotion, доступ 2026-09-02). DEEONE независимо подтверждает: «fullstats … один запрос в минуту на аккаунт; нельзя параллелить» (DEEONE, 2026-07, https://deeone.dev/blog/wildberries-api-etl-grabli-2026.html, доступ 2026-09-02). Есть открытая тема форума «CRITICAL BUG: новый метод продвижения /adv/v3/fullstats возвращает 0 в значениях: sum, views, clicks» (WB API Community, unknown, https://dev.wildberries.ru/forum/1441, доступ 2026-09-02, только заголовок) - это сигнал, что v3 fullstats в 2026 г. переживал миграцию с v2 и имел дефекты; статус исправления не проверен. Дайджест WB API за сентябрь 2025 (https://dev.wildberries.ru/en/news/146) индексируется по запросу fullstats, но прочитан не был. Список мутирующих методов (start/pause/stop/delete/deposit), `upd`/история платежей и normquery/cluster-статистика в этом раунде НЕ подтверждены источниками - см. «Не нашёл».

### (c) Отзывы и вопросы

Существует отдельная спецификация «Seller API Feedbacks and Questions» (Wildberries, unknown, https://openapi.wb.ru/feedbacks-questions/api/en/, доступ 2026-09-02, сниппет). Метод списка отзывов «позволяет получить список отзывов по заданным параметрам с пагинацией и сортировкой», поддерживает фильтр `isAnswered` (в Python-SDK - `is_answered=False`), и поле `productValuation` содержит оценку товара в отзыве (Wildberries / PyPI wildberries-sdk, unknown, https://dev.wildberries.ru/en/docs/openapi/user-communication и https://pypi.org/project/wildberries-sdk/0.1.147/, доступ 2026-09-02, сниппеты). Release note: «с 11 декабря поле valuation (средняя оценка всех отзывов) будет удалено из ответа метода Unanswered Feedbacks»; рекомендация - убрать обработку поля или получать средний рейтинг другим методом (Wildberries Release Notes, unknown - по соседству с дайджестом ноября 2025, https://dev.wildberries.ru/en/release-notes?id=291, доступ 2026-09-02, сниппет). Лимиты запросов и глубина истории отзывов не подтверждены; DEEONE прямо пишет «Feedbacks: явного ограничения глубины истории не указано» (DEEONE, 2026-07, https://deeone.dev/blog/wildberries-api-etl-grabli-2026.html, доступ 2026-09-02).

### (d) Поисковая аналитика

`POST /api/v2/search-report/report` «создаёт сводную аналитику о выдаче товаров в поиске» (Wildberries, раздел «Аналитика», unknown, https://openapi.wildberries.ru/analytics/api/ru/, доступ 2026-09-02, сниппет). «Методы поисковых запросов по вашим товарам доступны только с подпиской „Джем“» (Wildberries, unknown, https://dev.wildberries.ru/en/news/297, доступ 2026-09-02, сниппет). «Как и в методах воронки продаж, данные возвращаются максимум за последние 365 дней от момента запроса» (Wildberries, unknown, https://dev.wildberries.ru/en/docs/openapi/analytics, доступ 2026-09-02, сниппет). Новость «Поисковые запросы по вашим товарам» сообщает, что «ответ метода „Поисковые запросы по товару“ дополнен 8 полями и структурами price и medianPosition» (Wildberries, unknown, https://dev.wildberries.ru/en/news/297, доступ 2026-09-02, сниппет). Добавлены CSV-отчёты по текстам запросов (модели `SearchReportTextReq`/`SearchReportTextRes`, `SEARCH_QUERIES_PREMIUM_REPORT_TEXT`) (Wildberries, unknown, https://openapi.wildberries.ru/analytics/api/ru/, доступ 2026-09-02, сниппет). Поля `frequency`, `openCard`, `avgPosition`, `visibility` в сниппетах не подтверждены дословно - только `openCard` и `medianPosition`.

### (e) Тарифы

Ни один тарифный эндпоинт (`commission`, `box`, `pallet`, `return`, paid storage) в этом раунде НЕ подтверждён источником. DEEONE упоминает лишь, что «Tariffs: один метод; влияет на доступность данных других эндпоинтов» (DEEONE, 2026-07, https://deeone.dev/blog/wildberries-api-etl-grabli-2026.html, доступ 2026-09-02) - формулировка неясная, требует проверки.

### (f) Финансы

`reportDetailByPeriod` - детальный финансовый отчёт за период; параметры `limit` (число строк за вызов, рекомендация - по 100 000) и `rrdid` (курсор пагинации для отчётов длиннее 100 000 строк), `dateFrom`/`dateTo` (Kassy.Center / Infostart, unknown, https://kassy.center/blog/reportdetailbyperiod-wildberries/ и https://infostart.ru/1c/articles/2068048/, доступ 2026-09-02, сниппеты). Сниппет сообщает, что «прежний метод `GET /api/v5/supplier/reportDetailByPeriod` планировалось отключить 15 июля 2026» (сводка поиска по официальной странице openapi.wb.ru/statistics, unknown, https://openapi.wb.ru/statistics/excel_save/ru/, доступ 2026-09-02, низкая уверенность - преемник не назван). DEEONE: отчёт «пересобирается до 42 дней; требует ежедневной перезагрузки с полной перезаписью, а не инкремента» (DEEONE, 2026-07, https://deeone.dev/blog/wildberries-api-etl-grabli-2026.html, доступ 2026-09-02). В домене финансов появился отдельный хост `finance-api.wildberries.ru` (тот же источник).

### (g) Токены, лимиты, изменения 2025-2026

По разбору DEEONE API живёт на 11 доменах: `content-api`, `discounts-prices-api` + `dp-calendar-api`, `marketplace-api`, `supplies-api`, `statistics-api`, `seller-analytics-api`, `advert-api`, `feedbacks-api`, `common-api`, `finance-api`, `webhooks-api` (все `.wildberries.ru`) (DEEONE, 2026-07, https://deeone.dev/blog/wildberries-api-etl-grabli-2026.html, доступ 2026-09-02). Лимиты - модель Token Bucket с четырьмя параметрами (Period, Limit, Interval, Burst), различающимися по методу и типу токена; пример Marketplace: Personal/Service 300 за 1 мин, интервал 200 мс, burst 20; Basic/Test 150, burst 10 (там же). Типы токенов: Personal, Service (лимиты общие для всех токенов сервиса), Basic, Test (сниженные, общие); срок жизни токена 180 дней без автообновления (там же). Заголовки: `X-Ratelimit-Remaining` в обычных ответах; при 429 - `X-Ratelimit-Retry` (секунд до повтора), `X-Ratelimit-Reset`, `X-Ratelimit-Limit` (там же). Сниппет официальной страницы api-information: «X-Ratelimit-Remaining - число запросов, которые сейчас можно отправить без пауз; уменьшается на единицу после каждого запроса; присутствует во всех статусах, кроме 429; если он равен 0 и следующий запрос идёт без задержки - ответ 429»; «каждая категория имеет независимые клиенты со своими лимитами»; «в конце 2023 WB перешёл на гибкую систему токенов, где доступ к категориям настраивается выборочно» (Wildberries, unknown, https://dev.wildberries.ru/en/docs/openapi/api-information, доступ 2026-09-02, сниппет). Важно: DEEONE явно пишет «универсальный read-only флаг не упоминается», т.е. бит «только на чтение» по категориям в этом раунде НЕ подтверждён ни одним источником - это критично для допущения брифа о «split-токене read-only». Воронка продаж: существует `POST /api/analytics/v3/sales-funnel/products/history` (статистика по дням/неделям по товарам: переходы в карточку, корзина, заказы, выкупы) (Wildberries, unknown, https://dev.wildberries.ru/en/news/285 и https://dev.wildberries.ru/en/docs/openapi/analytics, доступ 2026-09-02, сниппет); дата отключения v2 и поле favorites не найдены. Дайджест WB API за март 2026 (https://dev.wildberries.ru/news/302/daidzhest-wb-api-mart-2026) индексируется, но не открылся.

## Лиды для следующего раунда

- Приоритет: противоречие/пробел по read-only биту. Бриф проекта предполагает «split-токен с битом read-only на категорию»; единственный прочитанный источник (DEEONE) его не упоминает. Нужен официальный текст api-information (попробовать `dev.wildberries.ru/ru/docs/openapi/api-information`, Google cache, web.archive.org, или README `github.com/wildberries-tech/api`).
- Официальный публичный репозиторий спецификаций `github.com/wildberries-tech/api` - открыть OpenAPI YAML напрямую (raw.githubusercontent.com), там же лимиты и `x-` расширения по каждому методу; `github.com/eslazarev/wildberries-sdk` как зеркало с историей коммитов (сроки миграций).
- Дайджесты: `dev.wildberries.ru/en/news/146` (сентябрь 2025), `news/161` (ноябрь 2025), `news/302` (март 2026), `news/285` (воронка v3) - открыть через web.archive.org, там должны быть даты отключения v2 sales-funnel, поле favorites, преемник v5 reportDetailByPeriod.
- Форум `dev.wildberries.ru/forum/1441` (fullstats v3 возвращает нули) и `forum/topics/1634` (неверные данные воронки) - проверить, исправлены ли дефекты.
- Тарифы: ни один эндпоинт не подтверждён; искать `common-api.wildberries.ru /api/v1/tariffs/commission|box|pallet|return` и `seller-analytics-api /api/v1/paid_storage`.
- Реклама: список мутирующих методов (`/adv/v0/start|pause|stop|delete`, `/adv/v1/budget/deposit`) и READ `upd`/`payments`, `stats/keywords`, normquery - взять из OpenAPI YAML.
- Отзывы: лимиты запросов и глубина истории (`take/skip` максимумы, `dateFrom`).
- Поисковая аналитика: подтвердить дословно поля `frequency`, `openCard`, `addToCart`, `orders`, `avgPosition`, `visibility`.

## Не нашёл

- Официальная документация dev.wildberries.ru: HTTP 498 на все 8 страниц; `openapi.wildberries.ru` - proxy refused. Первичный текст не прочитан ни для одной области.
- Бит read-only на категорию токена - не найден ни в сниппетах, ни во вторичном источнике.
- Дата отключения sales-funnel v2 и поле favorites - не найдены.
- Тарифные эндпоинты и paid storage - не подтверждены.
- Мутирующие методы рекламы, `upd`/платежи, normquery/cluster-статистика - не подтверждены.
- Лимиты и глубина истории для feedbacks/questions и stocks-report; гранулярность по складам в stocks-report - не подтверждены.
- Преемник `GET /api/v5/supplier/reportDetailByPeriod` после 15.07.2026 - не назван.
