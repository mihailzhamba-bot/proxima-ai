# c2-ads-efficiency - round 2

Дата доступа ко всем источникам: 2026-09-02. Ограничение раунда: сессионный лимит WebSearch (200/200) был исчерпан до начала раунда, поэтому все шесть поисковых запросов не выполнились; раунд шёл только через WebFetch по заранее известным URL. Из 11 запрошенных страниц прочитаны 6, четыре отклонены прокси («proxy refused the connection»), одна отдала пустой шаблон.

## Что искал и что нашёл

**Противоречие по цене Marketguru (приоритет).** Живая страница тарифов подтверждает: «Малый бизнес» - 4 990 ₽/мес с биддером на 10 рекламных кампаний, репрайсером на 50 товаров, 500 автоответов и 100 токенов «Оракул AI»; «Средний бизнес» - 19 990 ₽/мес (биддер 50 кампаний, репрайсер 250 товаров); «Крупный бизнес» - 29 990 ₽/мес (биддер 200 кампаний, репрайсер 1000 товаров); скидки за 3/6/12 месяцев - 10/15/20 %; «Расширение для Wildberries» - 990 ₽/мес отдельно; «Индивидуальный холдинг» - по заявке (Marketguru, дата публикации неизвестна, https://marketguru.io/prices, доступ 2026-09-02). Таким образом, 4 990 ₽ - это полноценный тариф с биддером, а не «тариф без биддера»; цифра «от 9 900 ₽» у Uniseller (2026-08-30) живой страницей не подтверждается и по правилу «первичный источник + свежесть» проигрывает. Однако второй независимый издатель для цены Marketguru не получен - поиск был недоступен; на странице тарифов нет упоминания триала (4-дневный триал в прошлом раунде взят со страницы /tools/bidder).

**WB Promotion API: fullstats и статистика нормализованных запросов.** Обе официальные страницы (https://openapi.wildberries.ru/promotion/api/ru/ и https://openapi.wildberries.ru/statistics/api/ru/) в этом раунде недоступны инструменту («proxy refused the connection»), поэтому поля, лаг и лимиты fullstats по-прежнему не подтверждены первичкой. Зеркало найдено: репозиторий eslazarev/wildberries-sdk (MIT, 42 звезды, Python/Node.js/Go/PHP/Rust) заявляет, что SDK «постоянно актуальные в соответствии с OpenAPI-спецификациями» Wildberries, спецификации хранятся в каталоге `specs/` (в т.ч. `specs/08-promotion.yaml`, `specs/11-analytics.yaml`, `specs/12-reports.yaml`, `specs/13-finances.yaml`), регенерация идёт через GitHub Actions при изменении спецификаций, а CHANGELOG фиксирует обновления несколько раз в неделю (GitHub, обновлён 2026-09-02, https://github.com/eslazarev/wildberries-sdk, доступ 2026-09-02). По README, в `specs/08-promotion.yaml` перечислены пути `/adv/v3/fullstats`, `/adv/v1/stats`, `/adv/v1/count`, `/adv/v1/balance`, `/adv/v1/budget`, `/adv/v1/payments`, `/adv/v1/upd`, `/adv/v0/auction/nms`, группа `/adv/v0/normquery/` (bids, list, stats), а также `/api/advert/v0/bids/recommendations`, `/api/advert/v1/bids`, `/api/advert/v2/adverts` и мутирующие `/adv/v0/pause`, `/adv/v0/start`, `/adv/v0/stop`, `/adv/v0/delete` (там же). Это первое подтверждение (среднее доверие, вторичный источник-зеркало), что статистика по нормализованным запросам существует как отдельный read-эндпоинт `/adv/v0/normquery/stats` - именно он нужен для правила «проигрышные/нерелевантные кластеры» без парсинга. Мутирующие пути (`pause`/`stop`/`budget`/`bids`) находятся в том же модуле, что и статистика - при выдаче read-only токена детектор обязан не вызывать их, и это стоит закрепить в allowlist.

Страница GitHub-топика `wildberries-api` дополнительно показывает актуальные SDK: salacoste/daytona-wildberries-typescript-sdk (TypeScript, 7 звёзд, обновлён 2026-08-09, «поддержка всех 11 API модулей»), dev-ik/seller-sdk (TypeScript, 1 звезда, 2026-08-19), ilyautov/marketplaces-mcp-ru (Python, 20 звёзд, 2026-08-01, MCP-сервер для кабинетов WB/Ozon: продажи, остатки, цены, финансы, отзывы); отдельных репозиториев только про рекламу (advert/fullstats) на странице нет (GitHub, доступ 2026-09-02, https://github.com/topics/wildberries-api).

**Поставщики.** WBStat.PRO публикует три тарифа по числу товаров: «Новичок» 2 990 ₽/мес (до 50 товаров; акция 14 950 ₽ за 6 мес, 23 920 ₽ за 12 мес), «Профи» 5 990 ₽/мес (50-500 товаров; 29 950 / 47 920 ₽), «Гуру» 8 990 ₽/мес (500+; 44 950 / 71 920 ₽) и бесплатную версию для теста; на главной странице нет раздела про аналитику рекламы, биддер или ДРР (WBStat.PRO, дата неизвестна, https://wbstat.pro/, доступ 2026-09-02) - для кластера C2 этот поставщик пока выглядит нерелевантным. JVO держит инструмент «Агент рекламы» (`/agent-reklamy`), заголовок страницы - «Автоматическое управление рекламой на маркетплейсах», но страница - лендинг с формой заявки (имя, телефон, email, ссылка на SKU, оборот) без правил, цен, триала и описания режима «рекомендация vs автодействие» (JVO, дата неизвестна, https://jvo.ru/agent-reklamy, доступ 2026-09-02); позиционирование «автоматическое управление» - слабый сигнал, что JVO, как и Marketguru, действует без approve-флоу. MPSTATS (https://mpstats.io/tariffs) снова отдала только заголовок «Тарифы MPSTATS - выберите доступ к платформе для продавцов» без таблицы цен; Anabar (https://anabar.ai/) отклонён прокси.

**Пользовательский голос, методика экономии, guardrails.** Поиск по Habr (страница выдачи требует JS) и любые форумные треды в этом раунде недоступны - вопросы о двойном учёте fullstats vs отчёт о реализации, окне атрибуции и публичной методике «сэкономленного бюджета» остаются открытыми. Новых свидетельств по промежуточному режиму «предложение → подтверждение → действие» не найдено.

## Лиды для следующего раунда

- Противоречие Marketguru 4 990 ₽ vs «от 9 900 ₽» (Uniseller) - живая страница подтверждает 4 990 ₽ с биддером; нужен второй независимый издатель с датой ≤3 мес (обзор, каталог, отзывы) или архивная копия страницы, чтобы понять, было ли повышение/акция.
- Прочитать сырой файл спецификации `specs/08-promotion.yaml` в eslazarev/wildberries-sdk (raw.githubusercontent.com) - извлечь схему ответа `/adv/v3/fullstats` (views, clicks, ctr, cpc, sum, atbs, orders, shks, sum_price, canceled, разрез days/nm), лимиты и описание `/adv/v0/normquery/stats` (какие метрики по кластерам, период, лимит); это обходит блокировку openapi.wildberries.ru.
- Аналогично `specs/11-analytics.yaml` / `specs/12-reports.yaml` / `specs/01-general.yaml` - найти эндпоинт остатков (`/api/v1/supplier/stocks`) и поля nmId/quantity для правила «реклама на товаре без остатка»; и `specs/13-finances.yaml` для сверки с отчётом о реализации.
- Новые сущности: salacoste/daytona-wildberries-typescript-sdk (TS, все 11 модулей - кандидат для коллектора на TypeScript), ilyautov/marketplaces-mcp-ru (MCP-сервер WB/Ozon), dev-ik/seller-sdk.
- JVO «Агент рекламы» - искать обзоры/кейсы с ценой и режимом (авто vs рекомендация); Anabar, Маяк, MPSTATS - страницы «реклама/биддер» и цены остаются не прочитанными (прокси/пустая страница), пробовать альтернативные URL (mpstats.io/pricing, справка help.mpstats.io, anabar.ai/tariffs).
- WBStat.PRO, судя по главной, не имеет модуля аналитики рекламы - проверить одной страницей и при подтверждении исключить из кластера C2.
- Пользовательский голос (двойной учёт fullstats vs финансовый отчёт, окно атрибуции WB) - только после восстановления поискового бюджета: vc.ru, Telegram-каналы, форум продавцов WB.

## Не нашёл

- Первичная документация WB Promotion API и Statistics API (fullstats: поля, лаг, лимиты; нормализованные запросы; остатки) - обе страницы openapi.wildberries.ru отклонены прокси; данные получены только через README SDK-зеркала (пути без схем).
- Второй независимый издатель для цены Marketguru и для цен любого RU-поставщика (поиск недоступен: лимит WebSearch 200/200 исчерпан на уровне сессии).
- Цены и рекламные функции MPSTATS (страница тарифов отдаёт только заголовок), Anabar (proxy refused), Маяк, LikeStats, Stat4Market, Aurum Sky, MPFINASSIST, Fullstats (VK) - не читались.
- Пользовательские отзывы/треды о двойном учёте между статистикой кампаний и отчётом о реализации и об окне атрибуции - поиск Habr отдал пустой JS-шаблон.
- Публичная методика расчёта «сэкономленного бюджета» и правила SKU-каннибализации - ни у одного из прочитанных источников.
- Промежуточный режим guardrails (предложение → подтверждение → действие) - у JVO и Marketguru позиционирование «автоматическое управление», описания approve-флоу нет.
