## Что искал и что нашёл

### Официальная поверхность данных WB по отзывам и вопросам (C3)

Официальная документация раздела «Отзывы» живёт по адресу `https://dev.wildberries.ru/en/docs/openapi/user-communication`, но при прямом запросе страница отдала HTTP 498, поэтому содержимое (пути, лимиты, поля) не подтверждено первоисточником (Wildberries dev-портал, дата неизвестна, https://dev.wildberries.ru/en/docs/openapi/user-communication, доступ 2026-09-02). По сниппету поиска этот же раздел включает методы «получить новые отзывы и вопросы, получить вопрос/отзыв по ID, управление вопросами, закрепление отзывов» (Wildberries dev-портал, дата неизвестна, https://dev.wildberries.ru/en/docs/openapi/user-communication, доступ 2026-09-02; уверенность низкая - сниппет). Хост боевого API отзывов - `feedbacks-api.wildberries.ru`, что подтверждает README архивированной PHP-библиотеки Dakword/WBSeller, где есть отдельные клиенты `$wbSellerAPI->Feedbacks()` и `$wbSellerAPI->Questions()` и отдельные ключи `'feedbacks'` и `'questions'` (GitHub Dakword/WBSeller, репозиторий архивирован 2026-02-12, https://github.com/Dakword/WBSeller, доступ 2026-09-02). Песочница - `feedbacks-api-sandbox.wildberries.ru`; в ветках форума WB API разработчики жалуются, что после POST-создания тестовых отзывов GET-методы возвращают пустые массивы, а рабочий рецепт - создать карточку в песочнице контента, указать существующий `nmID` и передать `isAnswered=false`; тестовые отзывы генерируются «примерно каждые 2 часа» (форум WB API, обсуждения 1479 и 1328, дата неизвестна, https://dev.wildberries.ru/forum/1479 и https://dev.wildberries.ru/forum/1328, доступ 2026-09-02). Из этого следует, что базовые «события» (новый отзыв, новый вопрос, флаг неотвеченности `isAnswered`) доступны через официальный read-only опрос; поля рейтинга, имени покупателя и rate-limit в этом прогоне не подтверждены - лид на раунд 2.

### Встроенный ИИ-ответчик WB и сторонние провайдеры автоответов

Wildberries совместно с Russ запустил ИИ-инструмент, который «генерирует и автоматически публикует» ответы на отзывы; раньше система «только предлагала черновики для ручного выбора»; продавец задаёт, на какие оценки ИИ отвечает автоматически, пример из статьи - «отвечать только на положительные отзывы (4–5 звезд), а негативные комментарии оставлять для ручной обработки»; ИИ учитывает текст отзыва, данные карточки и прежний стиль продавца, умеет вставлять артикулы рекомендуемых товаров, опубликованный ответ можно редактировать, при нехватке данных карточки ответ не публикуется; стоимость и место в кабинете не указаны (blog.click.ru, 2025-02-19, https://blog.click.ru/market-news/na-wildberries-zapushhen-ii-pomoshhnik-dlya-raboty-s-otzyvami-pokupatelej/, доступ 2026-09-02). Внимание: заголовок kubnews.ru датирует ту же новость «19 февраля 2026 г.» (kubnews.ru, 2026-02-19, https://kubnews.ru/obshchestvo/2026/02/19/na-wildberries-teper-za-prodavtsov-otvechaet-neyroset/, доступ 2026-09-02, не читал целиком) - конфликт дат, разрешить в раунде 2.

MPSTATS «Автоответы» работают в двух режимах: автопубликация по настроенным правилам либо модерация, при которой «ни один ответ не будет опубликован без вашего подтверждения»; сценарии срабатывают по рейтингу, товару, бренду, словам-триггерам, стоп-словам и наличию фото; есть «отложенная отправка» для естественности и обращение по имени; сервис заявляет около 610 000 ответов в месяц и 19 000 в день; командный доступ - до 3 сотрудников на «Бизнес» и до 10 на «Корпоративный», на «Базовом» нет; цены за тариф WB на странице не извлечены, для Ozon упомянуты Premium Plus 24 990 ₽/мес или надбавка 1,3 % от оборота (MPSTATS, дата неизвестна, https://mpstats.io/instruments/wildberries/autoreplies, доступ 2026-09-02). MarketGuru «Автоответы на отзывы» - сценарии с условиями по рейтингу и тексту, стоп-слова и триггеры, расписание отправки, более 1 000 готовых шаблонов, ИИ-ответы в трёх стилях («формальный, дружелюбный, стандарт») с подстановкой бренда и имени покупателя, «Уведомления о новых отзывах», «Подключение через официальное API WB», бесплатный пробный период «4 дня»; страница не различает автопубликацию и черновик с одобрением и не упоминает 152-ФЗ или место обработки LLM (MarketGuru, дата неизвестна, https://marketguru.io/tools/autoreviews, доступ 2026-09-02). Сервис «Ответо» по сниппету автоматизирует ответы на отзывы и вопросы на WB, Ozon и Яндекс Маркете «в ручном, полуавтоматическом и полностью автоматическом режимах» (SELLER MOON, дата неизвестна, https://sellermoon.ru/faq/wildberries/otvety-na-otzyvy-nejroset, доступ 2026-09-02; уверенность низкая - сниппет). Итог по режимам: паттерн «черновик + одобрение» явно поддержан MPSTATS (режим модерации) и был первой версией нативного инструмента WB; автопубликация с фильтром по звёздам - у WB, MPSTATS и, по-видимому, MarketGuru.

### Персональные данные покупателей и трансграничная обработка LLM

Ни одна из прочитанных страниц провайдеров (MPSTATS, MarketGuru, Sellego, WBRay) не раскрывает, где исполняется LLM, и не упоминает 152-ФЗ (те же URL, доступ 2026-09-02) - это находка: раскрытий нет. Правовая рамка по обзору cloud.ru: с 1 июля 2025 «первичный сбор ПДн граждан РФ должен происходить с использованием баз данных, расположенных в России»; передача данных иностранному сервису «считается трансграничной передачей персональных данных»; с 1 сентября 2025 согласие должно быть «явным и не может быть включено в другие документы»; к ПДн относятся не только ФИО и контакты, но и «история диалогов… IP-адреса и сочетание нескольких атрибутов»; при использовании ChatGPT и подобных «сведения могут передаваться OpenAI, Anthropic и другим провайдерам» (cloud.ru, 2026-08-07, https://cloud.ru/blog/ii-i-152-fz, доступ 2026-09-02). Ответственность остаётся на компании-операторе, а не на разработчике нейросети, и «обезличенные» для человека данные ИИ может вновь привязать к лицу (anti-malware.ru, 2026-06-17, https://www.anti-malware.ru/news/2026-06-17-111332/50389, доступ 2026-09-02; уверенность средняя - сниппет). Практический вывод для архитектуры (моё суждение, не цитата): текст отзыва с именем покупателя, отправленный во внешнюю иностранную LLM, попадает под трансграничную передачу; безопасный путь - удаление имени/идентификаторов до вызова модели либо российский LLM-провайдер; конкретные вендорские обязательства не найдены.

### Доказательства связи отзывов/рейтинга с конверсией и продажами

Найдены только вторичные утверждения без методики: «по данным Wildberries, влияние отзывов и рейтинга на позицию товара составляет от 3 до 10 %, причём отзывы о самом товаре составляют до 4 %» (Guru Seller / wbstat.pro, дата неизвестна, https://guruseller.ru/reyting-tovara-na-wildberries-algoritm-raschyota-ves-otzyvov-i-vliyanie-vremeni/ и https://wbstat.pro/faq/reyting-i-otzyvy-na-wildberries-novye-pravila-igry/, доступ 2026-09-02; уверенность низкая - без первоисточника, число незасорсено). Первичных исследований с цифрами конверсии по WB в этом прогоне не найдено.

### Поисковая видимость: официальный отчёт vs скрейпинг (C4)

Официальный путь: новость WB API «Поисковые запросы Wildberries - аналитика через WB API» - «методы поисковых запросов в WB API доступны только с подпиской Джем»; пять методов по поисковым запросам своих товаров; `POST /api/v2/search-report/report` отдаёт агрегированную аналитику «о выдаче товаров в поиске»; данные «максимум за последние 365 дней от даты запроса» (Wildberries dev-портал, https://dev.wildberries.ru/en/news/297, дата неизвестна, доступ 2026-09-02; уверенность средняя - сниппет поиска, страница отдала HTTP 498). Появление выгрузки отчёта «Поисковые запросы» через API датировано новостью 2024 года (АВОШОП, 2024, https://avoshop.ru/company/news/2024/wildberries_vygruzhat_dannye_otchyeta_poiskovye_zaprosy_teper_mozhno_s_pomoshchyu_api_/, доступ 2026-09-02; сниппет). Стоимость Джем: «Стандарт» - «22 990 ₽ за 30 дней», «Расширенный» - «42 990 ₽ за 30 дней»; отчёт показывает «полную воронку продаж по каждому запросу: показы, CTR, переходы, добавления в корзину и заказы»; в подписку входят «AI-инструменты для контента» и «аналитический бот WBot», «портрет покупателя», юнит-экономика и анализ ниш только в расширенном тарифе (SELLER MOON, 2026-03-19, https://sellermoon.ru/faq/wildberries/podpiska-dzhem-wb-2026-chto-vhodit-tarify-i-analitika-dlya-prodavcov, доступ 2026-09-02). Те же цены 22 990 / 42 990 ₽ повторяет сниппет поиска (второй независимый источник не прочитан целиком - цена остаётся одноисточниковой до раунда 2).

Скрейпинг-путь: Sellego снимает позиции роботом «до 12 страниц по ключу», «каждый час по 9 гео», обновляет «до 24 раз в сутки», ручная проверка «1 раз в час», раздельно показывает органику и рекламу («отдельно покажет динамику позиций по Рекламе»), «общую видимость карточки по всем ключам» и «количество просмотров по каждому отдельному ключу»; стартовый тариф 300 товаров/мес за 1 020 ₽/мес, пробный 30 ₽ за 3 дня; WB API и Джем как источник не упомянуты (Sellego, дата неизвестна, https://sellego.com/tracking/, доступ 2026-09-02). По сниппетам аналогичные трекеры позиций по ключам в органике и рекламе предлагают MP Manager (mpmgr.ru/product-tracker), MPSTATS (ежедневный мониторинг позиций), Нейромаркет (позиции + ключи конкурентов) (сниппеты поиска, доступ 2026-09-02; уверенность низкая). Вывод по кластеру: официальный отчёт даёт воронку «показы → CTR → корзина → заказы» по запросу только за деньги (Джем), а позицию по ключу и видимость по регионам сторонние сервисы получают скрейпингом публичной выдачи.

### Оповещения об изменениях карточки

WBRay «Мониторинг» отслеживает «цена, остатки, отзывы, рейтинг, медиа и контент», в т. ч. «первую фотографию» и данные продавца; уведомления в Telegram при изменении «цены, остатка, фотографии, отзывов или рейтинга»; токен API не нужен - достаточно «артикула или ссылки на товар» (т. е. публичный парсинг любой карточки, включая конкурентов); проверка «три раза в сутки»; модель оплаты кредитная (25 Rays при регистрации); «история начинается с первой проверки» (WBRay, дата неизвестна, https://wbray.ru/tools/wb-monitoring/, доступ 2026-09-02). У WB есть собственный отчёт «Календарь событий» в инструкциях продавца, но страница отдала только навигацию, содержимое не подтверждено (WB Partners, дата неизвестна, https://seller.wildberries.ru/instructions/ru/ru/material/events-calendar, доступ 2026-09-02). По сниппету у MP Manager есть модуль «Мониторинг» с историей изменений и уведомлением при снижении эффективности карточки (mpmgr.ru, сниппет, доступ 2026-09-02; уверенность низкая).

## Лиды для следующего раунда

- Конфликт дат нативного ИИ-ответчика WB (2025-02-19 у click.ru vs 2026-02-19 у kubnews): найти первоисточник в Telegram-канале пресс-службы WB или на seller.wildberries.ru; выяснить, бесплатен ли инструмент и входит ли в Джем.
- Подтвердить схему feedbacks API первоисточником в обход HTTP 498: `docs/Feedbacks.md` и `docs/Questions.md` в Dakword/WBSeller, eslazarev/wildberries-sdk (OpenAPI-спека), сниппеты форума - поля `productValuation`, `userName`, `createdDate`, `isAnswered`, лимиты запросов, эндпоинт ответа (`PATCH /api/v1/feedbacks/answer`?) и `unansweredCount`.
- Полный список 5 методов search-report (`/api/v2/search-report/...`), гранулярность (день? запрос×SKU?), поля (позиция, частотность, видимость), лимиты; второй независимый источник для цен Джем.
- Содержимое отчёта «Календарь событий» WB: фиксирует ли изменения фото/описания, доступен ли через API.
- Политики конфиденциальности MPSTATS/MarketGuru/Ответо: где хранится текст отзывов, какая LLM (российская/зарубежная), обязательства по 152-ФЗ; проверить Ответо и MP Manager напрямую.
- Первичное исследование связи рейтинга/отзывов с конверсией на WB (WB-аналитика, Data Insight, академические работы); источник цифры «3–10 %».
- Rate-limit и «свежесть» отзывов через API (задержка появления нового отзыва) - критично для SLA «неотвеченный > N часов».
- Пользовательские отзывы о сервисах автоответов (VC.ru, отзовики) - настроение и типовые претензии.

## Не нашёл

- Первичную документацию WB по отзывам/вопросам и по search-report (обе страницы dev.wildberries.ru - HTTP 498).
- Публичное раскрытие любым провайдером автоответов места исполнения LLM, трансграничной передачи или соответствия 152-ФЗ.
- Количественные доказательства (с методикой) связи падения рейтинга/негативных отзывов с падением конверсии или продаж на WB.
- Цены MPSTATS и MarketGuru за модуль автоответов для WB (на страницах инструментов - только пробный период и состав тарифов по числу сотрудников).
- Официальное описание метрик отчёта «Поисковые запросы» (частотность, позиция, видимость) - только вторичный пересказ SELLER MOON.
- Сервис, который явно детектирует «падение рейтинга» как событие или считает возраст неотвеченного отзыва как SLA - страницы описывают только уведомления о новых отзывах.
