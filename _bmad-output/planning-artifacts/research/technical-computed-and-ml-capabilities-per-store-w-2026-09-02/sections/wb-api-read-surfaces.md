### 2. Официальные READ-эндпоинты Wildberries: остатки, реклама, отзывы, поиск, тарифы, финансы

#### 2.1 Как получены факты и чего они стоят

Официальный портал недоступен из среды прогона: HTTP 498 на всех страницах документации, `openapi.wildberries.ru` отклоняется прокси [231][525]. Вся картина собрана по зеркалу спецификаций OpenAPI, которое наполняется из S3-зеркала инструментом `wb-spec-downloader` вне CI (провенанс - `scripts/download-specs-from-config.sh` и workflow зеркала, не README), поскольку антибот платформы блокирует автоматическую загрузку, а changelog генерируется языковой моделью по разнице файлов [225]. Последние коммиты спецификаций - 01-02.09.2026 [226]; внутри YAML даты нет. Официальный репозиторий `wildberries-tech/api` содержит только README 2022 года и как источник непригоден [223]; библиотека Dakword/WBSeller заархивирована 12.02.2026 и её каталог устарел [224]. Практический вывод: перед реализацией каждый эндпоинт проверяется живым вызовом, спецификация - только карта.

#### 2.2 Модель прав и allowlist

Каждая операция в спецификациях помечена машинными полями `x-readonly-method: true|false`, `x-category` и частью `x-token-types` [227]. Флаг «Только на чтение» при выпуске токена подтверждён одной публикацией: категории Контент, Аналитика, Цены и скидки, Маркетплейс, Статистика, Продвижение, Вопросы и отзывы, Рекомендации, срок жизни 180 суток [211]; справка вендора-интегратора описывает, что с таким токеном «нельзя изменить данные: цену, остаток на складе и так далее» [229]. Лимиты заданы по типам токена - Персональный, Сервисный, Базовый с секретом, Базовый; у Базового ограничения на порядки жёстче [213].

**Ловушка allowlist.** Мутирующие методы рекламы вызываются через GET: `/adv/v0/start`, `/adv/v0/pause`, `/adv/v0/stop`, `/adv/v0/delete`, наряду с POST `/adv/v1/budget/deposit` и PATCH ставок [416]. Фильтрация по HTTP-методу небезопасна - allowlist строится по полному пути и сверяется с `x-readonly-method`.

#### 2.4 Подписка «Джем»: что на самом деле гейтится

Раннее утверждение «методы поисковых запросов доступны только с подпиской» [206][510] уточнено спецификацией: запрета на сами методы нет, подписка влияет на лимит выборки `search-texts` (30 против 100 на продвинутом и премиальном тарифах) и на историю воронки длиннее года; CSV-отчёты по истории остатков создаются без подписки [213]. Цена подписки по вторичному источнику - 22 990 и 42 990 рублей за 30 дней [512], второго издателя нет.

#### 2.5 Снятие финансового отчёта

Удаление `GET /api/v5/supplier/reportDetailByPeriod` и его схемы зафиксировано в changelog зеркала записью от 16.07.2026 [622]; ранее тот же changelog помечал метод устаревшим с удалением 15 июля [622]. Об отключении 15.07.2026 и о новых методах независимо сообщают два издателя [614][220]. Соответствие полей опубликовано: `ppvz_for_pay` → `forPay`, `storage_fee` → `paidStorage`, `acceptance` → `paidAcceptance`, `delivery_rub` → `deliveryService`, `acquiring_fee` → `acquiringFee`, `sa_name` → `vendorCode`, `barcode` → `sku` [623]. Типовая ошибка миграции - конкатенация строковых сумм вместо арифметики [623].
