## Что осталось непроверенным

- Независимая рецензия тремя агентами (соответствие спайну AD-1..AD-18 построчно, полнота переноса решений D1-D24, сверка каждого утверждения об API с фактами) - прервана лимитом сессии.
- Рубрика качества PRD и проход по стилю (`bmad-review`, линзы структуры и прозы) - требует агентов, отложен.
- Живая проверка фактов API из отчёта R2: все они получены через зеркало спецификаций и помечены средней уверенностью.

## Замечание о расхождении, требующее решения

Спецификация задаёт для методов заказов и продаж лимит один запрос в минуту, тогда как проектная инвентаризация 30.08 зафиксировала десять запросов в минуту для заказов. Расхождение не влияет на текущий сбор (он укладывается в оба лимита), но должно быть разрешено до увеличения частоты: приоритет у живого замера, спецификация зеркала может отставать.
