# Глоссарий

Термины, у которых в проекте одно значение. Термин с двумя значениями - дефект спецификации.

| Термин | Значение |
|---|---|
| Кабинет | Один продавец WB с собственным набором API-токенов; в БД = один `tenant`. Сентябрь: ИП Амирова О. Ф. |
| Заказы | Строки WB Statistics `orders` за календарный день по полю `date`, без `isCancel`. Метрика тревоги. |
| Продажи / выручка | Строки `sales` с `saleID` на `S`; выручка = сумма `finishedPrice`. Возвраты (`R`) в выручку не входят. Справочная метрика. |
| Полный день | Календарный день, за который сбор завершён после его окончания. Текущий день и день последней частичной выгрузки - неполные, в норму не входят. |
| Норма | Медиана заказов (и отдельно выручки) за 14 последних полных дней по кабинету целиком. Пересчитывается каждое утро. |
| Отклонение | (вчера − норма) / норма в процентах, отдельно по заказам и выручке. |
| Аномалия | Отклонение, признанное сигналом (не шумом) и ранжированное по деньгам (M-04). Порог - открытый вопрос. |
| Сводка (brief) | Экран `/brief` веб-морды: статус данных, вчера против нормы, с M-04 - аномалии, с M-05 - план действий. |
| Ступень (M-xx) | Шаг лестницы M-00..M-05. Не фаза M1. |
| Единица работы | Один сеанс OpenHands + один связный PR + один результат, проверяемый Mike одним действием. |
| Прогон / run_id | Один запуск сбора или расчёта; каждая записанная строка несёт его `run_id`; прогон удаляется целиком. |
| Фикстура | Сохранённый реальный ответ WB API (без заголовков авторизации), на котором гоняются тесты. Канон - VPS `~/signal-inputs/fixtures/wb-api/` + S3. |
| Воронка | Дневные показатели по nmId из v3 sales-funnel / async CSV: открытия, корзина, заказы, выкупы. В сводке - октябрь. |
| Окно WB | Глубина, на которую Statistics отдаёт историю: ~6 месяцев скользящих (на 30.08.2026 - с 01.03.2026). |
| Боевая база / `proxima_test` | Одна база с данными кабинета и её копия для тест-запусков на том же Postgres. Сандбокс OpenHands - только `proxima_test`. |
| Ворота | Точки подтверждения заказчиком: 1 - инвентаризация, 2 - решения, 3 - единицы работы. |
