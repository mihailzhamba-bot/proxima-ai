# Interfaces

## Границы, решённые в спецификации

Прогон уровня T0: один документ + один Jira-комментарий, один контекст, публичных сигнатур и тестовых швов нет. Раздел пустой по правилу «граница, которую не пересекает ни один таск, не граница».

## Правила проекта (не выводятся из репо самостоятельно)

- Стек: docs-only прогон; Python 3.14 через uv (не системный 3.9); Node >=22. Проверка репо — `make verify` (полный контур), для docs-правок достаточно отсутствия поломок структуры.
- Язык: коммуникация и документация — русский; идентификаторы и термины (SCN-001, PMM-11, ADR, WBS, Reviewer BLOCK) — английские.
- Секреты не коммитить, не логировать. WB WRITE запрещён. Сibling-worktrees не мутировать.
- `git add -A` запрещён: в дереве чужие незакоммиченные потоки (`.codex/config.toml` и др.). Стейджить только свои файлы.
- Коммиты: атомарные, описательные, префикс docs/feat; co-author trailer по конвенции репо.
- Jira: cloudId `zhamba.atlassian.net`, проект PMM, PMM-11; комментарий markdown, статус и описание не менять (гейт утверждения).
- Недостающая зависимость или внешняя блокировка возвращается как BLOCKED, а не решается установкой/обходом.

## Из прогона (T0 single pass)

- Jira PMM-11 — комментарий «черновик к утверждению» (markdown), статус и описание тикета не менялись.
