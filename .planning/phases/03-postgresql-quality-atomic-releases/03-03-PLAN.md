# Plan 03-03 - Atomic domain releases with last-known-good

## Objective

Implement the release layer: three independent domain pointers (operational, inventory, financial) advanced by a single-transaction promotion of quality-checked fact batches, with typed failure visibility that never disturbs last-known-good, proven by pointer-level crash injection.
