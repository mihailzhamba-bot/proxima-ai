# Plan 03-01 - Quality, lineage, facts and release schema foundation

## Objective

Create the full Phase 3 schema additively (quarantine, normalized `order_count` facts, quality checks, unified lineage records, release attempts/promotions and three domain pointers, four runtime roles) in migrations `007_`..`009_`, with an enforced additive-only migration verifier and a Docker-free disposable PostgreSQL 16 roundtrip runner wired into the verify cycle.
