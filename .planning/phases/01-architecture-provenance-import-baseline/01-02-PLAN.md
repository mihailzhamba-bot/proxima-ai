1. Define versioned cross-language JSON Schemas for source artifacts, acquisition attempts and independent domain releases. Add valid/invalid fixtures and a Python checker using Draft 2020-12.
2. Create Mermaid source diagrams for system components, immutable data flow, one-VPS deployment boundary and delivery gates. Render deterministic SVG artifacts to a gitignored build directory using a pinned Mermaid CLI dependency.
3. Add a runtime-boundary checker that walks production manifests, entrypoints, imports, Compose references and environment keys. It must reject Playwright/browser/session/Torgstat production reachability while allowing explicit planning/provenance references.
4. Add a repository secret scanner with bounded patterns and fixture-based self-tests. It must scan tracked and staged content without printing matched secret values.
5. Add root `make verify` and CI. One exit code runs npm lockfile install, TypeScript tests/typecheck, Python tests, contract checks, migration discipline checks, provenance checks, Mermaid render, runtime-boundary check and secret scan.
6. Document the visual architecture, local commands and strict distinction between implemented Phase 1 boundaries and deferred Phase 2-8 runtime capabilities.

- All four Mermaid diagrams render, not merely parse.
- Contracts are machine-readable by both services and versioned independently from database migrations.
- `make verify` exercises every promised check and returns a single nonzero exit code on injected failures.
- CI uses the same root command, not a divergent command list.
- Production dependency graph has no Torgstat live session path or enable flag.
