- Imported destination bytes match the source commit, and inventory is machine-verifiable.
- No production dependency or entrypoint can resolve Playwright, a browser session or Torgstat.
- Source worktree fingerprints are identical before and after execution.
- Commit only this plan's owned files, then record commit SHA and verification output before independent review.
