# AGENTS.md

Правила для AI-агентов (Claude Code, Codex), работающих с этим репозиторием.

## Принцип минимальных прослоек

- Рабочие инструменты - Claude Code и Codex напрямую. Собственные agent harness, wrappers, orchestrators и runtime-прослойки над LLM API в этом репозитории запрещены.
- Не добавлять wrappers/orchestrators ради компенсации ограничений старых моделей: актуальные стандартные агенты закрывают типовые сценарии сами.
- Запрос к LLM из production-кода (collector, control-plane) через agent SDK - тоже прослойка и попадает под тот же запрет.
- Запрет enforced верификатором `tools/verify_runtime_boundary.py`: зависимости `@anthropic-ai/sdk`, `openai`, `anthropic` в runtime и их импорты в production-коде блокируются гейтом `make verify`.

## Исключение - только через отдельное решение

Новый harness допустим только при подтверждённом воспроизводимом gap стандартного агента. Порядок:

1. Заполнить шаблон `docs/decisions/harness-gap-template.md` полностью: сценарий, воспроизводимое ограничение стандартного инструмента, рассмотренные альтернативы, стоимость поддержки, owner.
2. Оформить отдельной задачей в Jira (проект PA) и утвердить до первой строчки кода.
3. Утверждённое решение хранится в `docs/decisions/`.

Если при аудите репозитория найдётся wrapper без такого решения - он либо удаляется, либо для него срочно заводится решение отдельной задачей.

## Прочие правила репозитория

- Единая точка входа проверок: `make verify`. Любое изменение проходит через него до коммита.
- Принципы проекта, контракты и fail-closed правила - в `.planning/PROJECT.md`.
- Документация и коммуникация - на русском; идентификаторы кода - на английском.
